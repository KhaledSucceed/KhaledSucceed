# Project Provenance — Letter Recognition

## Confirmed academic context

- **Course:** AIE121 — Machine Learning
- **Project:** Letter Recognition Using Machine Learning
- **University:** Galala University

## Recovered evidence

Recovered course-project presentations contain:
- the dataset definition;
- five-model comparison;
- documented performance metrics;
- team/presentation context.

The historical documented best result is **98.02% test accuracy / macro F1 with SVM RBF**.

## What was not recovered

- original notebook;
- original Python script;
- exact historical train/test split;
- exact hyperparameter/tuning record;
- raw historical output artifacts.

## Public reimplementation boundary

`src/train_evaluate.py` is a clean reproducible implementation created after recovery. It is **not** represented as the original university submission.

Historical metrics remain in `results/documented_results.csv`. Freshly reproduced metrics remain in `results/reproduced_results.csv`. They are intentionally separated.

## Evidence boundary

Recovered presentation files remain in the private academic archive because they may include team/student information. The public repository contains only professional, privacy-safe engineering evidence.
