- **Course:** CSE281 — Image Processing
- **Project:** Smoke Detection

## Recovered evidence

The historical Python implementation was recovered from the archived project record and is preserved publicly as:

`original_recovered/main.py`

## Clean implementation boundary

`src/smoke_detection.py` is a later cleaned CLI implementation created for reproducibility and maintainability. It is not presented as the historical source.
